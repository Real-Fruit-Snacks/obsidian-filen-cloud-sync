Built like it matters

A sync engine designed for correctness first, speed second.

01

End-to-end encrypted

Files and metadata are encrypted on your device with your Filen keys. The cloud stores ciphertext — nothing else.

02

Desktop and mobile

Windows, macOS, Linux, Android, iOS. The same plugin, the same vault, everywhere you take notes.

03

Conflicts without tears

Keep-both by default, keep-newer optional — and a side-by-side merge view when you want to decide yourself.

04

Version history

Browse and restore Filen file versions from inside Obsidian. Yesterday's draft is one click away.

05

Selective sync

Ignore folders, sync your theme and snippets between machines, share a curated settings set across devices.

06

Provably honest

A built-in self-test verifies auth, encryption round-trip and metadata interop against your live account.

Up in two minutes

A Filen account is required. Any plan works — including free.

Install the plugin

Find Filen Sync in the community plugin browser, install via BRAT, or copy three files into .obsidian/plugins/filen-sync.

Connect

Enter your Filen email and password once. The password derives your keys in memory and is never stored.

Sync

Your vault appears in Filen under Obsidian/<vault>. On your next device, point at the same folder and everything downloads.

Principles

Non-negotiables, written into the code and the tests.

No telemetry

The plugin talks to Filen's servers and nothing else. No analytics, no tracking, no third-party calls.

Trash-only deletes

Nothing is ever permanently deleted — local files go to system trash, remote files to Filen trash. Recovery is one click.

Open everything

MIT licensed. Design documents, research notes and 257 tests ship in the repo.
